# Security policy

Report a vulnerability privately through the **Security** tab of this repository ("Report a vulnerability"). Please do not open a public issue.

If you cannot use that, write to **weavesim@umitas.com**. Please do not put details of a vulnerability in a public place.

Include the version (`platform --version`), what you found, and how to reproduce it. Do not include confidential models or data.

Only the latest release is supported.
